# PoomSa — 한국어 문장 분석 연습실

**사이트:** https://goldhobbang.github.io/PoomSa/

학교 문법의 품사, 조사·관형사 세부 분류, 문장 성분, 서술어의 자릿수, 형태소를 연습하고 오답 이유를 확인하는 웹 앱입니다.

## 자유 문장 자동 분석

새 하이브리드 분석기의 흐름도, 복원 규칙표, 실행 가능한 파이썬 모듈과 예문 결과는 [구현 문서](docs/hybrid-analyzer.md)에 정리했습니다.

- 정답은 ‘부사격 조사’처럼 최종 분류명으로 표시하며 정오답 모두 최종 품사의 근거를 설명합니다.
- 등록된 맞춤법·띄어쓰기 규칙으로 가공한 뒤 분석하고 원문과 변경 사유를 표시합니다. 모든 오류를 교정하는 맞춤법 검사기는 아닙니다.
- ㅡ 탈락·르 불규칙·이- 생략·것/거 축약을 복원하고, 채점 후 형태소별 분리 표를 제공합니다.
- 웹에서는 자바스크립트로 실행하며 파이썬이나 로컬 LLM을 설치할 필요가 없습니다.

사용자가 **문장 한 줄을 입력하면 자동으로 문제를 생성**합니다. 정답지를 직접 만들 필요가 없습니다.

1. 브라우저에서 Garu 한국어 형태소 분석기(WebAssembly + 정적 모델)를 로드합니다.
2. 세종 품사 태그를 9품사와 조사·관형사 세부 분류로 변환합니다.
3. 주격·목적격·보격·부사격 등 조사 태그와 어미를 사용해 문장 성분을 추론합니다.
4. 서술어 어간과 논항 틀을 이용해 필수 성분과 자릿수를 추론합니다.
5. 형태소 분할과 원래 표면형을 교차 검사해 신뢰할 수 있는 예시를 선택합니다.
6. 추정 정답을 바탕으로 품사·문장 성분·자릿수·형태소 문제를 풀고 오답 해설을 확인합니다.

## 정확성 및 한계

- **미리 준비된 38개 예제**는 개별 정답표를 기준으로 채점합니다.
- **자유 문장**은 형태소 모델과 구문 규칙이 추론한 **잠정 정답**으로 채점합니다. 국립국어원의 공식 분석이나 검수된 정답은 아닙니다.
- 문맥에 따라 다른 해석이 가능한 조사, 보조사, 관형절·겹문장, 서술어 생략, 복합 용언 등은 틀릴 수 있습니다.
- 사전 밖 표현과 중의적인 범주는 조사·어미·절 문맥으로 후보를 선택해 **추정 정답으로 채점**하고 해설에 근거를 표시합니다.
- 첫 사용 때 모델과 WASM을 내려받지만 분석은 **브라우저에서 실행**되며 문장을 별도 분석 서버로 보내지 않습니다.
- 자동 분석 문장과 학습 기록은 localStorage에 저장됩니다.
- 형태소 분석: [Garu](https://github.com/ongjin/garu), MIT 라이선스, garu-ko 0.9.18. 문장 성분·자릿수 규칙은 PoomSa 자체 구현입니다.

## 지원 분류

- 9품사: 명사·대명사·수사·동사·형용사·관형사·부사·감탄사·조사
- 조사: 격조사(주격·목적격·보격·관형격·부사격·호격·서술격), 보조사, 접속 조사
- 관형사: 성상·지시·수 관형사
- 문장 성분: 주어·서술어·목적어·보어·관형어·부사어·독립어
- 서술어의 필수 성분 및 자릿수, 형태소 분리

## 로컬 실행

Node.js 22 이상에서 npm install, npm run dev 명령을 순서대로 실행합니다.
검사는 npm test, 빌드는 npm run build를 사용합니다.

## GitHub Pages

GitHub Actions 워크플로(.github/workflows/pages.yml)가 의존성을 설치하고 테스트·Vite 빌드를 수행한 뒤 dist 폴더를 배포합니다.
Settings → Pages → Source → GitHub Actions가 설정돼 있어야 합니다.

## 구조

- index.html — 웹페이지 및 사용자 입력
- app.mjs — UI, 채점, 자동 분석 등록, 학습 기록
- data.mjs — 검토된 연습 문장 데이터
- auto-analyzer.mjs — 형태소 태그 변환, 성분 및 자릿수 알고리즘
- model.mjs — Garu 브라우저 WASM 분석기 로딩
- hybrid-analyzer.mjs — 전처리, 사전·문맥 후보 결합, 음운 역복원
- grammar-rules.json — 웹·파이썬이 공유하는 규칙 사전
- python/poomsa_pipeline.py — 표준 라이브러리만 사용하는 파이썬 참조 모듈
- explanations.mjs — 샘플·자동 문장 공통 규칙 기반 오답 해설
- styles.css — 반응형 디자인
- tests/*.test.mjs — 형태소 모델 통합·데이터·자동 분석·UI 테스트
- vite.config.mjs — GitHub Pages 프로젝트 경로

## 프린트 기반 품사별 세분류 (38개 기본 문제)

선택 메뉴를 펼치는 대신, 품사를 누르면 해당 품사의 세부 분류 버튼이 그 아래에 계속 표시됩니다. 명사는 서로 다른 **두 기준**을 독립적으로 채점합니다.

| 품사 | 분류 항목 |
|---|---|
| 명사 | 고유/보통 명사 **및** 자립/의존 명사 |
| 대명사 | 인칭 대명사(1·2·3인칭), 지시 대명사(사물/장소), 미지칭·부정칭·재귀칭 대명사 |
| 수사 | 양수사/서수사 |
| 동사 | 자동사/타동사(보충 판별), 규칙/불규칙 활용 및 활용 유형 |
| 형용사 | 성상/지시 형용사, 규칙/불규칙 활용 및 활용 유형 |
| 관형사 | 성상/지시/수 관형사 |
| 부사 | 성분 부사(성상·지시·부정), 문장 부사(태도·양태/접속) |
| 감탄사 | 감정·의지·호응·구습(입버릇) |
| 조사 | 격조사·보조사·접속 조사, 격조사는 주격·목적격·보격·관형격·부사격·호격·서술격 |

**규칙 활용** 안의 'ㅡ 탈락', 'ㄹ 탈락'은 불규칙이 아닙니다. 불규칙의 세부 선택지는 ㄷ/ㅂ/ㅅ/르/우/여/러/너라/거라/ㅎ을 포함합니다. 활용 분류는 품사의 하위 종류와 구별해 별도 기준으로 표시합니다.

**정확성:** 샘플은 예제 정답을, 자유 문장은 형태소 모델·사전·문맥 규칙이 만든 추정 정답을 기준으로 채점합니다. `hybrid-3`는 조사 결합 조건과 어간·어미 후보를 비교해 빠진 공백을 복원하고 모델을 다시 실행합니다. 수 관형사·단위 의존 명사·본용언과 보조 용언·접속/부사격 조사·고유 명사를 문맥으로 판별합니다. 기존 저장 문장은 다시 분석하기 전까지 채점을 막습니다. 중의적인 ‘만큼’의 다른 해석은 설명과 함께 인정합니다. [오류 재현 및 검증 기록](docs/analysis-regressions.md)을 참고하세요.

구현: `taxonomy.mjs`에 분류 체계를 중앙 집중화했고 `tests/taxonomy.test.mjs`에서 범주와 예시를 검증합니다.
