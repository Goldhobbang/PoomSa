# PoomSa / 품사

문장을 **품사 / 문장 성분 / 서술어의 필수 성분과 자릿수 / 형태소** 네 가지 관점에서 직접 분류하고 채점하는 국어 학습 사이트입니다.

![Static Site](https://img.shields.io/badge/deploy-GitHub%20Pages-184c3b?style=flat-square)

## 사용하기

GitHub Pages를 활성화하면 사이트 주소는 다음과 같습니다.

**https://goldhobbang.github.io/PoomSa/**

최초 설정은 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions** 로 지정하세요. 설정이 완료되면 `.github/workflows/pages.yml`이 `main` 브랜치 변경마다 자동 배포합니다. **Pages를 활성화하기 전에는 배포 워크플로가 실패하며 위 링크도 열리지 않습니다.**

로컬 개발:

```bash
python3 -m http.server 5173
# http://localhost:5173
```

ES 모듈을 사용하므로 브라우저에서 `file://` 경로로 직접 여는 방식은 권장하지 않습니다.

## 기능

- **품사 채점:** 명사, 대명사, 수사, 동사, 형용사, 관형사, 부사, 감탄사, 조사. 조사는 독립된 단어로 다루되 어미는 품사로 제시하지 않습니다.
- **문장 성분 채점:** 주어, 서술어, 목적어, 보어, 관형어, 부사어, 독립어. 여러 어절로 이뤄진 구를 한 성분으로 제시할 수도 있습니다.
- **서술어 자릿수:** 한 자리·두 자리·세 자리 서술어 및 **필수적 부사어** 판별.
- **형태소 분리:** `철수/가`, `학생/이` 같은 형태소 경계 구분과 자립/의존·실질/형식 해설.
- **18개 기본 예제:** 학교 문법 개념을 중심으로 직접 작성된 예제. 문제별 채점과 해설을 제공합니다.
- **자유 문장:** 새 문장을 입력한 다음 **임시 분리를 편집**하고, 품사·문장 성분·서술어 자릿수를 등록해 **사용자 정답표 기준으로 채점**합니다.
- **학습 기록:** 채점 결과와 직접 만든 문제는 브라우저 `localStorage`에 보관됩니다. 계정이나 서버는 사용하지 않습니다.

> **정확성 안내:** 자유 문장에 대해 언어 모델이나 국어사전 기반의 정밀 자동 분석·정답 생성을 제공하지 않습니다. 입력 시 자동 제안은 미검증 초안일 뿐이며, 사용자가 확정한 정답으로만 채점합니다. 임의 문장의 형태소·문장 성분을 완벽하게 자동 채점한다고 주장하지 않습니다.

### 직접 만든 문장 등록

1. **자유 문장**으로 이동해 문장을 입력합니다.
2. `/`로 어절 내부의 형태를 분리하고 단어마다 품사를 선택합니다. 조사와 어미가 동일한 개념이 아닌 점에 주의하세요.
3. 각 문장 구성 요소의 문장 성분과 **필수 성분 여부**를 검토하고 서술어 자릿수를 선택합니다.
4. 형태소 연습 대상을 지정하고 저장하면 **분석 연습**에서 채점할 수 있습니다.
5. 여러 어절이 하나의 구를 이룰 때는 문장 입력 시 `|`로 경계를 지정할 수 있습니다. 예: `나는 | 책상 위에 | 가방을 | 놓았다.`

### 테스트

```bash
node --check app.mjs
node --check data.mjs
node --test tests/grammar.test.mjs
```

종속성이 없는 순수 HTML / CSS / JavaScript 정적 사이트입니다.

## 구조

```text
index.html                 화면 골격
styles.css                 반응형 디자인
data.mjs                   해설이 달린 학습용 문장 데이터
app.mjs                    채점·자유 문장 등록·기록·UI
tests/grammar.test.mjs     데이터 및 문법 일관성 검사
.github/workflows/pages.yml  GitHub Pages 자동 배포
```

## 개발 시 주의

품사와 문장 성분은 서로 다릅니다. 예컨대 `빠르게`는 형용사 `빠르다`의 활용형으로 문장에서는 부사어 역할을 하지만, `빨리`의 품사는 부사입니다. **보격 조사 `이/가`**, **필수적 부사어**, **의존 명사 `대로`와 조사 `대로`** 같은 경계 사례는 문제와 해설에서 문맥을 기준으로 구별합니다.

학습용·비상업적 사용을 목적으로 제작했습니다. 예문과 해설은 이 저장소의 학습용 데이터이며, 자동 생성 분석 결과를 국어사전의 공식 분석으로 오인하지 마세요.
