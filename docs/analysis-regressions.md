# 자동 분석 오류 재현과 수정 — hybrid-3

## 확인한 원인

2026-10-18에 사용자가 제시한 두 문장과 공백을 제거한 변형을 분석했다. 배포 커밋 `8bfa036`의 Actions 아티팩트 `12101221541`에서 실제 Garu 0.9.18 WASM과 모델을 확보해 실행했다. 원 모델의 결과는 `tests/garu-reported-fixtures.json`에 보관했다. 규칙 대체 엔진의 결과와 실제 WASM 실행을 구별했다.

1. **올바른 모델 태그 덮어쓰기.** 원 모델은 `친구/NNG + 와/JKB`, `같이/MAG`, `가/VV + 아야/EC`, `하/VX + ㄴ다/EF`를 출력했다. 자체 조사 사전이 `와`를 접속 조사로 덮어썼다. 모델이 없을 때는 미등록어의 끝에서 `이`, `야`를 무조건 떼어 `같/이`, `가/야`라는 잘못된 명사·조사를 만들었다.
2. **공백을 최종 단어 경계로 간주.** 붙인 문장을 모델이 여러 형태소로 분석해도 마지막 단계에서 한 공백 덩어리로 다시 묶었다. 일부만 붙인 경우에는 모델의 `너만큼은아/NNG` 같은 큰 명사 후보와 `사과/NNG + 하/XSV + ㄴ/ETM` 후보를 검증 없이 채택했다.
3. **문맥 분류 누락.** `첫째`의 서수사 해석과 관형사 해석을 구별하지 못했다. 수량 관형사 뒤의 `개`, 관형사 `다른`과 형용사 활용형 `다른`, 본용언 `가야`와 보조 용언 `한다`를 함께 판단하지 못했다.
4. **저장 결과.** 새 알고리즘을 적용해도 이전 버전의 저장 결과가 재분석 중에 표시·채점될 수 있었다. 업데이트 전의 잘못된 정답을 계속 쓰지 않도록 차단했다.

실제 두 문장의 원 모델 출력에는 고유 명사 태그가 없었다. 따라서 이 사례의 직접적인 원인은 고유 명사 모델 자체가 아니었다. 별도로 NNP 오태그를 주입해 `첫째`, `딸`, `같이`, `가야`의 판정을 검사하고, 실제 고유 명사 `가야`, `김하늘`이 불필요하게 쪼개지지 않는 반례도 검사했다.

## 구현

1. 기존 공백과 원문을 보관한다. 어간·어미, 체언·조사, 기능어, 모델의 어휘 후보로 각 위치의 분절 후보를 생성한다.
2. Viterbi 빔 탐색으로 후보 경로를 비교한다. 조사 결합 조건, 수량 표현, 관형사형 뒤의 의존 명사, 연결 어미와 뒤 용언, 알려진 단어 보호를 점수에 반영한다. 공백은 추가하지만 문장 내부의 문자를 삭제하거나 바꾸지 않는다.
3. 큰 명사 후보에 내부 문법 경계가 있는지 검사한다. 다만 명사들로만 구성된 정상적인 복합어는 보호한다. 문맥 없이 모든 미등록 문자열을 고유 명사로 간주하지 않는다.
4. 공백을 복원했으면 문장 전체를 Garu에 다시 전달한다. 복원된 문장의 위치를 기준으로 토큰을 묶으므로 옛 위치를 새 문장에 재사용하지 않는다.
5. 문맥으로 최종 판정한다. `와/과`는 대등 연결과 동반 관계를 구분한다. 수 관형사 뒤 단위 명사와 성상 관형사 뒤 일반 명사를 구별한다. `가야 한다`는 본용언과 보조 용언이 이루는 서술어로 처리하고 본용언의 논항 구조를 사용한다. 모든 연결 어미 뒤의 동사를 보조 용언으로 바꾸지 않는다.
6. 저장된 분석 버전을 갱신한다. 원래 입력과 교정 옵션으로 다시 분석하고 ID를 유지한다. 재분석 도중에는 예전 정답을 렌더링하거나 채점하지 않는다.

## 결과 예시

| 표현 | 분석 | 품사·세부 분류 |
|---|---|---|
| 너만큼은 | 너 / 만큼 / 은 | 인칭 대명사 / 보조사 / 보조사 |
| 아는 대로 | 알 / 는 + 대로 | 동사 활용형 + 의존 명사 |
| 친구와 같이 | 친구 / 와 + 같이 | 보통 명사 / 부사격 조사 + 성분 부사 |
| 가야 한다 | 가 / 아야 + 하 / ㄴ다 | 본동사 활용형 + 보조 동사 활용형 |
| 첫째 딸이 | 첫째 + 딸 / 이 | 수 관형사 + 보통 명사 / 주격 조사 |
| 사과 한 개를 | 사과 + 한 + 개 / 를 | 보통 명사 + 수 관형사 + 의존 명사 / 목적격 조사 |
| 다른 사람에게 | 다른 + 사람 / 에게 | 성상 관형사 + 보통 명사 / 부사격 조사 |
| 주었다 | 주 / 었 / 다 | 동사 활용형 |

‘너만큼은’의 `만큼`은 이 문장에서 한정 해석을 우선한다. 비슷한 정도·한도의 뜻으로 읽는 부사격 조사 해석도 가능하므로 품사와 문장 성분 채점에서 다른 해석을 인정하고 해설에 사유를 표시한다. 이를 다른 문장의 모든 `만큼`에 무조건 적용하지 않는다.

## 검사 범위

- 제시된 두 문장의 정상 공백·공백 제거·부분 공백·복사한 강조 표시 등 **7가지 입력**에서 단어 경계·형태소·태그·세부 분류·역할·자릿수 기대값을 검사한다.
- 기존 24문장의 역할·자릿수 검사를 유지하며, 각 문장의 공백을 제거해도 형태소와 태그가 같은지 검사한다.
- 규칙 경로, 실제 배포 WASM, CI의 npm Garu 경로를 각각 검사한다. 모델 출력을 저장한 회귀 검사는 실제 모델 통합 검사를 대체하지 않는다.
- 고유 명사, 일반 명사·기능어 NNP 오태그, `친구와 철수가`와 `친구와 같이`, `한 개`와 `새 개`, `다른 사람`과 `성격이 다른 사람`, `먹지 않는다`와 `아프지 않다` 등을 반례로 검사한다.
- UI 검사는 세부 분류 선택·색상·해설, 중의적 분석의 인정, 저장 결과 갱신 중 채점 차단을 포함한다.
- Python 참조 구현과 JS의 분절·태그·복원 플래그를 대조한다.

이 검사는 해당 오류와 회귀를 막는 검사이며 한국어 전체에 대한 정확도 측정값이 아니다. 제한된 사전과 문맥 규칙으로 모든 중의적 문장이나 임의의 고유 명사를 완전히 복원할 수 있다고 보장하지 않는다.
